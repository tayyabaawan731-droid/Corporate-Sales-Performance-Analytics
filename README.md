# Corporate Sales & Performance Analytics Tracker

## 📊 Project Overview

The **Corporate Sales & Performance Analytics Tracker** is an interactive Power BI dashboard developed to analyze corporate sales performance and distribution KPIs.

The dashboard provides a clear view of sales performance through interactive slicers, KPI cards, trend analysis, product performance charts, matrix tables, and advanced DAX calculations.

## 🎯 Objectives

* Analyze overall corporate sales performance
* Monitor Year-over-Year (YoY) growth
* Track Year-to-Date (YTD) sales
* Calculate moving averages
* Analyze sales by region, department, and product
* Identify sales trends and performance patterns
* Support data-driven business decision-making

## 🛠️ Tools & Technologies

* **Microsoft Power BI**
* **DAX (Data Analysis Expressions)**
* **Data Analysis**
* **Data Visualization**
* **Business Intelligence**

## 📌 Key Features

### KPI Cards

The dashboard includes important performance indicators:

* Total Sales
* YTD Sales
* YoY Growth %
* Moving Average

### Interactive Slicers

The dashboard provides interactive filtering through:

* Year
* Region
* Department
* Product

### Sales Trend Analysis

The trend graph visualizes sales performance over time and helps identify changes and patterns in sales activity.

### Product Sales Performance

A horizontal bar chart compares sales across products and helps identify high-performing and low-performing products.

### Matrix Table

The matrix provides detailed sales analysis across regions and departments for easier comparison and performance evaluation.

## 🧮 DAX Metrics

Advanced DAX measures were used to create dynamic performance calculations, including:

* **Total Sales**
* **Year-over-Year Growth**
* **Year-to-Date Sales**
* **Moving Average**

These calculations update dynamically according to the selected dashboard filters.

## 🚀 How to Use

1. Download the `.pbix` Power BI file from this repository.
2. Open the file using **Microsoft Power BI Desktop**.
3. Use the Year, Region, Department, and Product slicers.
4. Explore the KPI cards and sales trend.
5. Analyze product performance.
6. Use the matrix table for detailed regional and departmental analysis.
